# Lomo Camera 1.1

**More Lomo. Less Lomo. Your choice.**

This release adds a single strength slider to the famously simple Lomo Camera:

- 0% – unfiltered camera colours
- 100% – the original, carefully calibrated Lomo look
- 200% – richer colour separation, stronger contrast, increased saturation and classic dark corners
- Real-time changes in the live viewfinder and full-resolution saved photos
- Remembers your chosen strength between launches

No filter menus, accounts, advertisements, analytics, network access, or new permissions.

**Android 13 or newer.** Open-source, GPL-3.0-only.

Download or update the official, F-Droid-signed version through https://f-droid.org/packages/com.harristownapps.lomocamera/ when version 1.1 becomes available there. GitHub debug builds are for testing and use a separate package name.
